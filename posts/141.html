我给几个 AI 分身和四台云电脑发钥匙：一套 4 年 38 元的 1Password 实操

先说一个今天刚发生的场面。

我在给三台云端电脑绑定 API 密钥，来回填了十几次安全卡片，一把刚生成的新密钥还不小心出现在一张截图里。按规矩，那把钥匙当场作废、吊销重发——因为密钥只要进过聊天记录和截图，就必须按「已泄露」处理。

这不是我一个人的狼狈。这是 Agent 时代每个重度用户迟早要撞上的墙：你雇的 AI 越多，它们要用的钥匙就越多，而大多数人递钥匙的方式，还停留在「复制，粘贴进对话框」。

人用密码，一天输不了几次。Agent 用密码，是按任务计的：登录网站、调 API、读家里的 NAS、连云服务器，一天几百次起步。调用频率涨了两个数量级，泄露面也跟着涨了两个数量级——聊天记录里躺着的、配置文件里明文写的、日志和截图里顺带出去的，每一处都是一个迟早爆的点。

所以密码管理器在 Agent 时代的角色变了。它不再是「帮人记住密码的备忘录」，而是给 Agent 发钥匙的权限网关：钥匙分仓存放、按最小权限发放、每把钥匙可单独吊销、每次取用留痕。谁掌握这套网关，谁的 Agent 大军才跑得安全。

风向标是 1Password 自己。今年 10 月，它正式推出了面向 AI Agent 的功能：Agent 需要登录时，请求发到你这里，你批准，它代填，密码本体不经过 Agent。连做密码管理器的公司都看明白了——下一个十年，输密码的主力不是人，是 Agent。

我自己这套是怎么搭的，全部是正在跑的真实配置：

第一，专库专用。我建了一个只给 Agent 用的保管库，里面只放 Agent 真正需要碰的东西：家里 NAS 的专用账号、几个服务的 API 密钥。我的个人主库——银行、邮箱、证件——Agent 永远碰不到。哪天这个库整个泄露，我的损失也封顶在这里。

第二，每个分身一把独立的钥匙。我同时跑着几个 AI 助手分身和四台云端电脑（僚机），每个分身配一个独立的 Service Account，只授权它读、写那一个专库，权限在创建时定死、之后不可更改。要停哪个分身，吊销它那把令牌就行，其他分身毫发无损。这就是权限分离的实地版：不是「信不信任 AI」的问题，是爆炸半径的问题。

第三，取用不走聊天。Agent 要用 NAS 凭据，是自己用命令行从库里取，落到本机一个只有自己能读的文件里，全程不经过对话框、不进日志。我要给它新密钥，走的是保险库的安全卡片，值不进聊天、不经过我的手。反过来说，今天那把上了截图的钥匙为什么必须死——因为它破了这条线。

第四，浏览器登录走「批准—代填」。Agent 到了登录页，我这边点一下批准，密码直接填进去，它从头到尾没见过密码长什么样。看不到，就不可能说漏。

这套东西我也交过学费，两个坑都是亲身踩的：

一个坑是「假故障」。有十来天，我的 Agent 往库里写东西一直超时，我一度以为是权限没给对。最后查明：权限毫无问题，是调用脚本的一个输入细节让命令行工具一直在傻等。为这件事我误判了好几轮。教训是，Agent 工具链的坑大多不在产品，在你自己的调用方式——下结论之前，先把自己的手查干净。

另一个坑是「假连接」。界面上明明显示已连接，真到了要填充的时候却填不进去、转头去用别的通道。连接状态和实际可用，是两件事，必须实测验真，不能看图标放心。这一条，我在好几台机器、好几个服务上重复学过。

最后说价格，这部分可能才是很多人点进来的原因。

1Password 官方价：个人版每月 3.99 美元、按年付；家庭版每月 5.99 美元，可以拉 5 个人。照官方价用四年，个人版约合人民币 1370 元。

我这套是闲鱼上买的：4 年，38 元。不是每月 38，是四年总共 38，摊下来一年不到十块钱，约等于官方价的 2.8%。这类渠道的常见形态是家庭版席位：卖家开家庭组，你进组占一个位置，每个人有自己独立的私密库。

上这种车有三条避坑须知，都是硬知识：

一，家庭组的组织者看不见你的私密库内容，这一点是 1Password 的架构保证，可以放心；但组织者握着「协助恢复账号」的权力。所以核心资产怎么放，心里要有数：要么自己当组织者开组拉人，要么拼车席位只放日常账号，最核心的那几个另作安排。

二，车会翻。卖家跑路、家庭组解散、账号被回收，都可能发生。防法是定期把库导出一份离线备份（连同那张写着 Secret Key 的应急表一起，锁进抽屉），车翻了，数据还是你的。

三，只在闲鱼站内交易，看卖家在售时长和真实评价，拒绝任何「先确认收货再拉组」的话术。38 块钱不值得赌，但也不值得为它花超过十分钟。

回到开头那把死在截图里的钥匙。Agent 时代的安全感，不来自「我用的密码更复杂了」，而来自一套结构：钥匙不进聊天、不落明文、不共用一把、不出事时能单独吊销。这套结构搭好之后，我出门在外，手机上说几句话，分身们自己登录、自己取钥匙、自己干活，我不用守着电脑点授权，也不用把任何一把真钥匙交到任何人——包括 AI——手里。

38 块钱买的不是一个密码管理器。是让一支 AI 队伍能放心跑起来的发钥匙系统。这个账，怎么算都划算。
