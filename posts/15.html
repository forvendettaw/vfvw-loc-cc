GitHub 是全世界超大的免费工具箱，做自媒体的人却几乎不去。

去的人少，不是因为它难用，而是没人告诉你该搜什么。这篇帖子想回答的就是一个问题：一个做内容的人，从找选题到发布，到底能在 GitHub 上搜到什么？下面 12 个开源仓库全部免费、有手就能跑，刚好覆盖这条完整链路。

先说选题，这是一切的起点。MediaCrawler（NanmiCoder/MediaCrawler，6.8 万 star）做的是小红书等平台的笔记和评论采集，攒起来就是自己的选题库；last30days（mvanhorn/last30days-skill，6.5 万 star）聚焦近 30 天的真实口碑型选题；RSSHub（DIYgod/RSSHub，4.6 万 star）的思路是万物皆可 RSS，全网更新一站收齐。三个仓库对应三种来源：平台里正在发生的讨论、最近一个月的口碑动向、持续订阅的信息流——选题库就是这样建起来的。

选题定了，接下来是视频生产，这也是清单里仓库最多的一环。MoneyPrinterTurbo（harry0703/MoneyPrinterTurbo，13.6 万 star）输入主题就能自动产出短视频成片；yt-dlp（yt-dlp/yt-dlp，20.3 万 star）负责全网视频音频下载，方便二创存素材；faster-whisper（SYSTRAN/faster-whisper，2.6 万 star）把口播和播客一键转成文字，比原版快数倍；VideoLingo（Huanshere/VideoLingo，1.9 万 star）做字幕翻译对齐加 AI 配音；LosslessCut（mifi/lossless-cut，4.5 万 star）做无损剪切，切素材不需要重编码。从出片、下载、转写、译制到剪辑，一条视频流水线的每个环节都有人写好了开源方案。

图文排版的需求轻一些，两个仓库就够。doocs/md（1.3 万 star）是长文 Markdown 排版器，样式能打；Excalidraw（excalidraw/excalidraw，13.4 万 star）是手绘风白板，适合画知识图和笔记配图。一个管文字，一个管配图，图文内容的呈现环节就齐了。

最后一步是把所有环节串起来。n8n（n8n-io/n8n，20.8 万 star）能把选题、写稿、生图、发布接成一条自动化流水线；anthropics/skills（18.4 万 star）是官方的 AI 技能包，作用是把经验沉淀成固定流程。到了这一层，省下的就不只是单个环节的时间，而是整个 workflow 里的重复劳动。

回到开头的问题：在 GitHub 上到底该搜什么？答案其实很朴素——照着内容生产的顺序搜，选题、视频、图文、自动化，每一步都有免费的现成仓库在等着。

不过光有清单不够。这类工具，90% 的人收藏完就忘了，真正拉开差距的从来不是装了几个，而是把其中一个用成肌肉记忆。所以与其十二个全收进收藏夹，不如现在就挑一个，装上，开始用，看看它会给你带来什么变化。
