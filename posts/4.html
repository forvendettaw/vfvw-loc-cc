御三家这轮更新全部落地了。

御三家这轮更新全部落地了。作为三家都在付费的普通用户，这篇不跑分、不堆参数，只回答一个问题：每家到底适合干什么。

时间线是这样的：10 月初 Gemini 4 Argon 上线，加上之前的 GPT-6 和 Claude 5.5，三家这一轮算是出完了牌。我的订阅情况——Claude 用的是学校 edu 版（2.5 倍用量的 Pro），GPT 是 20 刀的 Plus，Gemini 领到了一年免费 Pro。

先给结论，从最喜欢到最不喜欢：Claude、ChatGPT、Gemini。context window、max output 这类参数我不打算聊，作为消费者根本感受不到区别，不如只谈实际用途。

Claude：最全能的一个，我 80%~90% 的日常都花在它身上。交给它任何任务基本都不会出问题，联网搜索尤其靠谱——让它找一篇 paper，不给链接、不给原文，它真能找到，还能定位到我要的内容。coding 能力也毋庸置疑，我的代码基本都在 Claude Code 里跑。Codex 和 Gemini 的 coding 我没大量试过，就不做对比了。

ChatGPT：文生图的首选。同样是生成一个雪人，Claude 花了 7 分钟，交出来的东西像个 2D 图案；GPT 不到 1 分钟，给了一个活泼又真实的雪人。AI 味是重了点，但两者完全不在一个档次。其他类型的图片生成需求，GPT 对 Claude 也基本是同样的碾压。

Gemini：便宜、慷慨，外加一门独门绝技——语音转文字。日常我基本不打开它了，等待时间长，回答也笨笨的、钝钝的。但处理音频找它准没错：录一段音，让它分析内容或者出 transcript，这个场景里 Claude 和 GPT 都帮不上忙。它也确实慷慨，身边几乎人人都有 Pro，开 Google Cloud 还送 300 刀的 API 免费额度。

还有一个现实的提醒：如果你长期身处国内，我的推荐排序会变成 Gemini = ChatGPT > Claude（国产模型我了解很少，这里不展开）。原因是 Claude 的封号风险不小，好几个朋友假期回国用 Claude，要么被封了，要么有被封的风险；另外两家我身边还没听说过类似情况。

最后想说，99% 的人都是普通使用者，挑模型没必要纠结参数。真正决定体验的，是你自己用起来时那些具体的细节——参数是纸面上的，日常的手感才是自己的。
