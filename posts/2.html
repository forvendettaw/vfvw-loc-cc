GitHub 上有一大批完全免费的开源工具，但几乎没人用——这里整理出 10 个

GitHub 上有一大批完全免费的开源工具，但几乎没人用——这里整理出 10 个，每一个都值得花几分钟了解。

VoiceStudio：开源、完全本地运行的 ElevenLabs 平替。语音克隆、语音设计、视频配音、听写、转录、有声书制作都很强。

ppt-master：把 PDF、Word 或者一个主题，变成真正可编辑的原生 PowerPoint 文件。

gods-eye-view：浏览器里的卫星模拟器，数据是真实的。在 3D 地球上实时叠加飞机、船只、卫星、摄像头、天气、火灾等公开数据。

rea：用 Agent 逆向工程任何软件，从行为一直深入到二进制。

diagram-design：让 Agent 画出设计师不会嫌弃的编辑风格图表。提供 45 种图表类型，输出自包含的 HTML + SVG，还能匹配品牌风格。

paperclip：自托管平台，把多个 AI Agent 当成「员工」来统一管理。

mattpocock skills：工程师们每天都在用的 Coding Agent 技能集合。

ECC：Claude Code 等 Agent 的全套工程化 harness，涵盖技能、记忆与安全。内置数百个技能、专用 Agent、hooks、规则，以及记忆与安全扫描。

andrej-karpathy-skills：基于 Karpathy 的观察提炼出 4 条规则，用来改善 LLM 写代码的行为。

claude-mem：本地记忆系统，自动捕获 Coding Agent 的会话，并注入到后续会话中。

以上项目在 GitHub 上都能直接搜到，全部开源免费。
