DeepSeek Bot 已经上线，装个插件就能用

上线不到一天就在 GitHub 收获 250+ 星，DeepSeek Bot 这个项目最值得看的，是它把 AI 助手从「每次都要从头交代背景」变成了「一支记得住你习惯的团队」。

先泼盆冷水：它不是 DeepSeek 官方出品，是民间开发者做的，以 Apache 2.0 协议开源，代码放在 GitHub 上，搜 FeiZhuLulu/DeepSeek-Bot 就能找到。名字里带着 DeepSeek，热度来得又快，很容易让人误认成官方产品，这一点先讲清楚。

它跟 Grok Bot 是一个路子：给 DeepSeek Harness（DSH）套了一层多 Bot 团队界面。每个 Bot 都能自己起名、写角色说明、挑模型。我装完当天就试了一把，搭了个【飞叔自媒体创作团队】，三个岗位：选题 Bot、文案 Bot、诊断反馈 Bot；再建一个群把它们全拉进去，群里默认配一个主管（DSH 里叫 Chief），加上主管一共四个角色。

和过去用单个 AI 助手相比，差别主要在两处。

一是记忆。以前每开一个新任务，背景都得从头讲一遍；这个插件最戳我的是「持久化」——每个 Bot 有独立的上下文和长期记忆，会攒着你的习惯和偏好，下次接着用就行，不用再重复交代。

二是调度。以前几个角色一起干活，得自己一个个点名安排；现在我只管往群里发需求，主管自己判断该派给谁。这个主管机制还顺带省 token——不然群里每个 Bot 都抢着回，一天能烧掉不少。

实际用下来的感受是：每个角色干起活来，真像一名员工。

安装也简单：DSH 侧边栏 → 插件 → 添加插件 → 输入 ds-bot。国内记得把源切成国内镜像，装完启用，重启一下 DSH 就能用。

两个提醒不能省。一是它刚上线不到一天，是第三方开源项目，不是官方产品；二是这些 Bot 会读写文件、跑命令，消耗的是你自己的模型额度，重要操作最好自己盯一眼。

我的判断是：对已经在用 DSH 的人来说，它值得装来一试，持久记忆和自动派活解决的是真实存在的麻烦；但它是刚上线不到一天的社区项目，能动文件也烧你自己的额度——日常辅助可以放心用，重要环节还得自己把关。
