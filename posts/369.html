Qwen4-Max 发布：能力往上涨，成本往下降

@protonpoker
AI2026年11月19日约 2 分钟
18px
阅读进度 0%

Qwen4-Max 发布，最值得看的不是新架构或 1M token 上下文，而是一个少见的组合：能力往上涨，成本往下降。

这就带出一个直接的问题：相比上一代 Qwen3.8-Max，它到底强在哪、省在哪，这些数字又是在什么口径下成立的。

大模型换代有个已经被习惯了的剧本：能力上去了，成本跟着上去，想要更强的模型，就得接受更多的 token 消耗和更贵的调用价。Qwen3.8-Max 就是这次的参照系。

官方给出的对比是：Qwen4-Max 的表现超过 Qwen3.8-Max，同时 token 用量最多减少约 50%；在官方内部评测中，平均每个任务的成本下降超过 60%。至少在这组数据里，「更强」和「更省」同时成立。

底座本身也换了：Qwen4-Max 基于新的 MoE 架构构建，具备原生视觉能力，上下文窗口达到 1M token。

这些能力投向的是真实工作场景。官方列出的提升包括更熟练地使用专业工具、更强的长程任务执行，以及更高质量的交付物；它能处理的任务横跨 3D 建模、游戏开发、制造、金融、法律、医疗，直到前沿科学发现。官方给它的定位，是工作、创作和探索上的 AI 队友。

数字的边界也要交代清楚：成本下降超 60% 出自官方内部评测，属于厂商自测口径；开源方面，官方目前确认的是较小 Qwen4 模型的开放权重将陆续发布。

目前 Qwen4-Max 的 API 已在 QwenCloud 上线，也可以在 Qwen Studio、QwenWork 和 Qoder 里直接试用。入口分别如下： Blog: https://qwen.ai/blog?id=qwen4-max API: https://www.qwencloud.com/models/qwen4-max Token Plan: https://www.qwencloud.com/pricing/token-plan

最后落在账单上：输入 $1.5 / 百万 token，输出 $4.5 / 百万 token，implicit caching $0.075 / 百万 token，三项全部低于 Qwen3.8-Max——其中 implicit caching 一项，降了 70%。
