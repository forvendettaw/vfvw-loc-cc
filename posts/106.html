一文解锁国行 iPhone：国内直加海外 eSIM、突破 2 张上限，这次用防白苹果的 Erosion-CN

国行 iPhone 有一条很别扭的限制：人在国内，海外运营商的 eSIM 加不进去。按苹果的规则，你得先出境、开着定位，系统才放行，而且一台手机最多存两张。香港号、旅行流量卡想常备几张轮着用，门都没有。

这道锁不在硬件上。国行机的基带和天线并不缺什么，拦路的是 iOS 的一份系统缓存——MobileGestalt。系统靠它判断一台机器卖给哪个地区、该开哪些功能。很多人试过改里面的地区代码，结果添加 eSIM 时照样弹「不适用于你所在的国家或地区」。真正管事的，是缓存里另一个地区限制标志：green-tea。把它翻过去，地区代码和销售地区都不用动，国内网络下直接扫码就能加，2 张的上限也跟着解除。

最近把这条路走通的工具不止一个，GestaltX 的隐藏开关这几天传得很广。而今天要说的 Erosion-CN，是另一条更值得细看的线：它今天才在 GitHub 公开，到今晚已经攒了 849 颗星、197 个 fork。它是上游项目 Erosion 的简体中文分支，界面 100% 本地化，但它真正的卖点不是多几个开关，而是「不把手机写坏」——项目副标题直接写着：防白苹果安全加固版。

为什么改缓存这件事值得这么紧张？因为 MobileGestalt 写坏的代价是真实的：轻则重启后修改被系统丢弃、全部回弹，重则相机黑屏、白苹果，甚至拿别人的备份乱恢复，把基带和 eSIM 搞出异常。Erosion-CN 的十项核心改进里，一大半在修这类事故：原版写入走了临时文件替换，破坏了缓存文件的 Inode 和属主权限，重启即被系统重建，它改成强制原位覆盖；原版 Plist 编辑器把布尔值和相机变焦的浮点参数误存成整数，存完相机直接黑屏，它改成按 CoreFoundation 原始类型无损直通；写入协议换成从偏移 0 原位覆盖、按需截尾、再用 F_FULLFSYNC 强制刷盘，断电也不会留下 0 字节空文件。

动手之前的安全栏也做得比同类细。点「应用」先弹变更对比预览，每条键值改前改后逐项核对；写入前自动存一份 PreApplyGestalt 快照，写完立刻从磁盘读回做全量校验，不一致就自动回滚。最关键的一步是偏移不靠硬编码：它在运行时只读扫描本机加载的 libMobileGestalt.dylib，实时算出这台机器、这个系统版本对应的 CacheUUID 和槽位偏移，CacheUUID 不唯一、长度对不上、有效位不对，任何一项不过，开关直接锁定不许写。备份文件带 SHA-256 摘要和机型、系统四重指纹，还被排除在 iCloud 和换机迁移之外——旧手机的缓存备份，永远不会被带到新手机上覆写。

实际操作反而没那么复杂。前提先说清：设备要是国行支持 eSIM 的机型，比如 iPhone Air、iPhone 18 系列；系统须是 iOS / iPadOS 27.0–27.2 或 27.3 beta 1，完整支持。iOS 26 只能用壁纸、容器浏览这些外围功能，写不了 MobileGestalt，别硬试。第一步永远是拿电脑做一次完整备份。第二步，去 GitHub 的 Releases 页下载最新版 IPA（目前是 v0.7.2），用支持 App Group 的签名工具自签安装——SideStore、AltStore、Feather、Sideloadly、Impactor、iLoader 都在官方支持列表里，个人 Apple ID 就行；它能在运行时自动探测重签工具注入的 group 容器，省了手动对 App Group 的折腾。第三步，首次打开先确认主页日志识别到了 App Group，并把应用自动生成的原厂备份 OriginalGestalt.plist 再导出一份到「文件」里留底。第四步，在国行底层缓存分区确认动态解析显示精确匹配，再打开「解除国行底层限制」——它动的就是 green-tea 与 not-green-tea 这两个布尔槽位；在「地区与功能准入」里也可以顺手开「解除地区限制」，监管型号会自动按本机硬件填。最后点应用，过一遍 Diff 预览，确认写入，手动重启一次。

重启之后，进「设置 → 蜂窝网络 → 添加 eSIM」，人在国内、连着国内网络，直接扫运营商给的二维码就行。加完一张可以接着加，香港号、旅行卡、地陪卡一起存着，不再卡在 2 张。加好后把蜂窝数据切到新卡实测一下能不能上网，漫游开关按运营商说明来。双实体卡槽还在，加上多张 eSIM 常备，国行机反而成了组合最灵活的那个版本。想改回去，随时在应用里关掉开关重新应用，或者用原厂备份一键还原；已经加好的 eSIM 不会因为改回原值被删掉。系统大版本升级后缓存会被重建，届时重新走一遍开关即可，写进缓存的配置本身重启不回弹，也不靠 App 常驻续命。

它能拆的也不止 eSIM 这把锁。Apple 智能有一张四要素体检卡：销售地区、监管型号、芯片准入、系统实时回读，一键补齐缺失项；iPhone 15 Pro、16、17 还能解锁默认只给最新代硬件的个人实时翻译和 iOS 27 音频智能，旧机型开 Apple 智能时会联动带上相册「消除」和备忘录手写体合成。影像侧有混音、空间音频录制、零延迟抓拍这些硬件槽位开关，健康侧有高血压趋势评估。工具箱里还塞了应用存档备份还原和容器缓存清理，专治「系统数据」莫名暴涨。每一项原生硬件已经支持的能力都会被自动锁定，防止误关降级。

把丑话说在最后：改系统缓存这件事，再多的护栏也改变不了它的性质——这是拿研究工具动系统的底层配置，只适合在自己的设备上折腾，完整备份是底线，售后和合规风险自己掂量。但如果一定要拆这把锁，选工具的标准不该是开关多不多，而是它肯花多少功夫证明自己写不坏。Erosion-CN 今天第一天公开就冲到近 850 星，靠的大概正是这一点：先把回滚和校验做满，再谈解锁。
